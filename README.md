# SmartCell · Face Control 365 и Smart Age Journal

Статический кит для переноса в тему `virtus` (WordPress): чистые HTML, CSS и JS без
сборщиков и зависимостей. Стенд для согласования с клиентом —
https://smartcell-frontend.gelovonarfas.workers.dev — после переноса гасится.

## Николаю: что брать

| что | где |
|---|---|
| Блоки — оригиналы для шаблонов, в каждом якорь на Figma и поля ACF | `sections/*.html` |
| Статья-образец целиком (брать её, не `vm-article.html`) | `vm-article-oblik.html` |
| Собранные страницы — порядок блоков и подключения | `index.html`, `vm-blog.html`, `vm-category.html` |
| Токены из Figma — подключать как есть, не править | `assets/css/tokens.css` |
| Сквозные правила и переменные `--sc-*` | `assets/css/base.css` |
| Стили и скрипты по блокам, имена совпадают с секциями | `assets/css/sections/`, `assets/js/` |
| Медиа; что заменить перед публикацией — в README папки | `assets/img/`, `assets/b04b/`, `assets/video/` |
| Карта блоков, поля, поведение скриптов, вес, что остаётся Николаю | `docs/HANDOFF.md` |
| Что изменилось между передачами, с пометкой «файлы» или «разметка» | `CHANGELOG.md` |
| Правила системы: BEM с префиксом, только переменные, один брейкпоинт | `smartcell/DESIGN.md` |

Готовый архив без служебного лежит в релизах: каждая передача — тег `handoff-N`.

## Николаю: что не трогать

Это наш стенд и рабочие инструменты, к теме отношения не имеют:
`deploy/`, `scripts/`, `wrangler.jsonc`, `.deployignore`, `.github/`, `CLAUDE.md`,
`smartcell/PRODUCT.md`, `smartcell/PHOTO-GUIDE.md`. В архив релиза они не входят.

## Как накатывать обновления

Пункт в `CHANGELOG.md` с пометкой **файлы** — взять новую версию файла как есть.
С пометкой **разметка** — перенести правку в шаблон темы; файл секции соответствует
одному template-part, имена классов не меняются. Точные строки: `git diff handoff-1..handoff-2`.
