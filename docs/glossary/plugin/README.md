# Плагин «SmartCell — Клітинна абетка»

Готовый архив: `smartcell-abetka.zip` (рядом). Исходники: папка `smartcell-abetka/`.

Что делает:

1. **Карточки терминов** в админке: раздел «Клітинна абетка», 270 терминов, у каждого поля (определение, «простими словами», формы слова, якорь, галочка «підсвічувати в статтях»). С 1.2.0 переводимые поля с вкладками языков qTranslate, как в статьях.
2. **Импорт из CSV** одной кнопкой: создаёт карточки, при повторном запуске обновляет их по якорю, дублей не делает.
3. **Шорткод `[sc_abetka]`**: выводит страницу абетки (буквы H2, термины H3 с якорями, определения) той же разметкой, что в ките (`vm-glossary.html`).
4. **Автоссылки в статьях**: первое упоминание термина становится ссылкой на абетку с подсказкой при наведении. Разметка и вид как на стенде: https://smartcell-frontend.gelovonarfas.workers.dev/preview-abetka-tooltips

В тексты статей в базе плагин ничего не пишет: ссылки подставляются на выводе (`the_content`). Выключили режим или плагин, и статьи выглядят как раньше.

**После активации плагин ничего не меняет на сайте**: режим автоссылок по умолчанию «Вимкнено».

## Установка и тест, не трогая сайт

1. Плагины → Добавить новый → Загрузить плагин → `smartcell-abetka.zip` → Активировать. Обновление на новую версию так же: загрузить zip, WordPress предложит «Заменить текущую версию загруженной». Карточки терминов и настройки хранятся в базе и при замене сохраняются, повторный импорт не нужен.
2. Клітинна абетка → Налаштування та імпорт → «Імпортувати» (файл можно не выбирать, CSV лежит внутри плагина). Должно появиться «створено 270».
3. Создать тестовую статью (можно с паролем или приватную) с текстом любой статьи журнала. Запомнить её ID.
4. В настройках: режим **«Тест»**, вписать ID тестовой статьи, указать адрес страницы абетки, сохранить.
5. Открыть тестовую статью: термины подчёркнуты пунктиром, при наведении подсказка. Остальные статьи сайта не меняются.

Запуск на весь журнал: режим «Увімкнено».

Через WP-CLI импорт тоже есть: `wp sc-abetka import` (или с путём к своему CSV).

## Обновление до 1.2.0 (с 1.1.x)

1. Загрузить zip через «Загрузить плагин» → «Заменить текущую версию».
2. Клітинна абетка → Налаштування та імпорт → «Імпортувати» один раз. Карточки переводятся в новый формат полей (по якорю, ничего не теряется). До этого всё работает и на старых полях.
3. **Автоссылки больше не вешаются на `the_content` сами** (иначе они попадали в лид в шапке). В шаблоне статьи вызвать для тела текста:

```php
echo sc_abetka_apply( apply_filters( 'the_content', get_the_content() ) );
```

Или обернуть то, что тема уже выводит как текст статьи: `sc_abetka_apply( $html )`. Проверки режима, языка, «Тест» по ID — внутри функции; на остальных страницах HTML возвращается как был. Старое поведение (всё через `the_content`) включается галочкой «Де підставляти» в настройках.

**Почему не работает на странице.** Админу внизу кода страницы плагин пишет комментарий `<!-- sc-abetka 1.2.0: … -->`: работает или нет и почему (режим, ID в «Тест», тип записи, язык, адрес абетки), сколько терминов в индексе и сколько ссылок поставлено. Если в комментарии «працює», а ссылок 0 или статистики нет, значит `sc_abetka_apply()` не вызывается для текста. Сайт с W3 Total Cache: после изменений сбросить кеш страниц.

## Языки (qTranslate)

Переводимые поля карточки: заголовок (как в абетке, со скобками), «Назва без дужок», «Визначення», «Простими словами», «Форми слова». Они хранятся в формате qTranslate (`[:ua]…[:ru]…[:en]…[:]`), и плагин сам сообщает qTranslate-X о своих полях (фильтр `i18n_admin_config`): в карточке те же переключатели «Українська / Русский / English», что в статьях.

- **Страница абетки** на /ru/ и /en/ показывает текст на языке страницы; перевода нет — украинский. Подписи «Визначення:» / «Простими словами:» на языке показанного текста (RU и EN подписей — наш перевод, нужно вычитать; фильтр `sc_abetka_label`).
- **Подсказка в статье** только на языке страницы: нет перевода определения — ссылка без подсказки, украинский текст в RU/EN-статью не подставляется. Строка «Натисніть на слово…» в RU и EN — наш перевод, вычитать (фильтр `sc_abetka_tip_more`).
- **Формы слова** для каждого языка свои, на вкладке языка: по ним термин ищется в RU/EN-текстах.
- `**слово**` в текстах таблицы (так клиника выделила жирным, сейчас у «Регенеративний потенціал») на странице абетки выводится жирным, в подсказке без звёздочек.

## Страница абетки

В текст страницы «Клітинна абетка» вставить `[sc_abetka]` вместо набранного руками текста. Якоря терминов (`id` у H3) берутся из карточек: на них ведут ссылки из статей.

**Оглавление-«чипсы» справа.** Тема строит оглавление по H2 из текста записи, а на странице абетки в тексте записи только шорткод, H2 он выводит уже при показе. Поэтому в шаблоне страницы абетки пункты оглавления берутся из плагина (с версии 1.1.0):

```php
<ol class="vm-article__toc-list">
  <?php echo function_exists( 'sc_abetka_toc_html' ) ? sc_abetka_toc_html() : ''; ?>
</ol>
```

Выводит `<li><a class="sc-t-small" href="#letter-a">А</a></li>` по каждой букве, как в ките; якоря те же, что у H2 шорткода. Раздел английских терминов: заголовок и чипс «A–Z», якорь `#letter-latin`, как в ките. Если нужен массив, а не готовый HTML: `sc_abetka_toc_items()` → `[ ['id' => 'letter-a', 'label' => 'А'], … ]`.

Запасной вариант без шаблона: на странице настроек внизу есть готовый HTML всей абетки, его можно вставить в редактор как есть. Тогда оглавление темы увидит H2, но после правок терминов HTML нужно вставлять заново.

## Как это выглядит для редактора

- Новая статья: ничего делать не нужно, термины подсветятся сами.
- Не нужны ссылки в конкретной статье: галочка «Без автопосилань на абетку в цій статті» в боковой панели редактора.
- Не нужно подсвечивать конкретное слово нигде: в карточке термина снять «Підсвічувати в статтях».
- Термин должен вести на страницу услуги, а не в абетку: в карточке заполнить «Посилання на сторінку послуги». Сейчас так задуманы Пластична хірургія, Естетична медицина, Неофіброліфтинг®, Банк клітин; адреса услуг нужно вписать руками, в CSV их нет.
- Новый термин: «Додати термін», заполнить якорь, букву, определение и формы слова (по одной в строке).

## Правила автоссылок

- Только первое упоминание термина в статье, всего не больше 7 ссылок (настройка).
- Не трогаются: заголовки H1–H6, готовые ссылки, `blockquote`, `figure`, `aside`, `nav`, `code`, а также всё внутри элемента с классом **`sc-no-terms`**. Этот класс можно повесить на любой модуль, который выводится через `the_content` и где ссылки не нужны (например, «Коротко»).
- Сначала длинные формы: «клітинна регенерація» раньше, чем «регенерація».
- Целые слова, без учёта регистра; аббревиатуры (PRP, HIFU, RF-терапія) с учётом регистра. «PRP-терапія» термином PRP не считается.
- Три вида апострофа (`'` `’` `ʼ`) считаются одним, неразрывный пробел между словами термина допустим.
- 46 частотных слов и названий услуг идут с выключенной подсветкой (список в `docs/glossary/README.md`).

## Что нужно от темы

- Текст статьи должен выводиться через `the_content()` (или `apply_filters( 'the_content', … )`). Если он идёт из ACF-поля мимо этого фильтра, вызвать функцию напрямую:
  `echo sc_abetka_autolink( $html, sc_abetka_index( sc_abetka_lang() ), sc_abetka_page_url(), 7 );`
- Стили подсказки рассчитаны на разметку и переменные кита: селектор `.vm-article__body a.sc-term`, переменные `--primary`, `--border`, `--hairline`, `--sc-space-*` и т. д. Плагин подключает свои копии `vm-term-tip.css` и `term-tip.js` только на страницах, где работает фильтр. Если эти файлы уже подключены в теме, снять галочку «Підключати CSS і JS підказок із плагіна».
- Язык берётся из qTranslate (`qtranxf_getLanguage()`, код `ua` приводится к `uk`). По умолчанию включена только украинская версия. RU и EN включаются галочками; переводы названий и форм там ещё не вычитаны, определения появятся, когда их впишут во вкладки RU/EN карточек.

## Что проверено и что нет

Проверено в чистом WordPress (WordPress Playground, последняя версия WP, PHP 7.4 и 8.3): импорт и повторный импорт, страница абетки (270 терминов, 25 разделов), автоссылки на тексте статьи «Облік фібробластів» и на тексте с крайними случаями, режимы «Тест» и «Увімкнено», сохранение настроек, экраны админки без предупреждений PHP.

1.2.0 проверено с qTranslate-X 3.4.6.8 (языки ua, ru, en): вкладки языков в карточке, сохранение перевода из редактора, RU-подсказка и RU-страница абетки, повторный импорт не стирает RU, карточки старого формата читаются и переводятся импортом, `sc_abetka_apply()` и галочка «автоматично», жирный из `**`.

Не проверено: работа в теме `virtus`, вид подсказки в теме, галочка «без автопосилань» в редакторе сайта, команда WP-CLI. Это видно только на сайте, поэтому первый запуск лучше в режиме «Тест».

## Обновление терминов

Клиника прислала новую таблицу → мы пересобираем CSV (`docs/glossary/src/build.py`) → на сайте «Імпортувати» с новым файлом. Импорт обновляет поля из CSV и добавляет новые термины, ничего не удаляет; «Посилання на сторінку послуги» сохраняется. Украинский текст из CSV перезаписывает сайт (таблица клиники главная); RU и EN из CSV попадают только в пустые языки, перевод, сделанный на сайте, импорт не затирает. Галочка «Підсвічувати в статтях» берётся из CSV, ручная правка на сайте при импорте перезапишется.

Сборка архива из кита: `sh scripts/build-abetka-plugin.sh` (копирует в плагин свежие CSV, CSS и JS и пакует zip).
