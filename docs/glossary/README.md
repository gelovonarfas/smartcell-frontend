# Клітинна абетка — термины для импорта и автоссылок

`smartcell-abetka-terms.csv` — 270 терминов из таблицы клиники «Клітинна абетка VIRTUS» (2026-11-19, вторая версия таблицы: +18 терминов, нумерация сдвинулась, `id` = номер в новой таблице).
UTF-8 с BOM, разделитель — запятая, формы внутри ячейки — через ` | `.

## Колонки

| колонка | что это |
|---|---|
| `id` | номер из таблицы клиники |
| `anchor` | якорь термина в абетке: `id` у H3 («HTML-якір»). Ссылка из статьи — `…/klitynna_abetka#anchor`. После запуска не менять, иначе старые ссылки сломаются |
| `letter` | буква (H2 в абетке) |
| `title_uk` | термин как в таблице, со скобками: так он выводится в абетке |
| `term_uk` / `term_ru` / `term_en` | основное название без скобок. **RU и EN — наш перевод названий, нужно вычитать** |
| `definition_uk`, `simple_uk` | «Медичне визначення» и «Простими словами» — дословно из таблицы, только украинский |
| `autolink` | `1` — подставлять ссылку автоматически, `0` — нет: общеупотребимые слова (Сон, Стрес, Травма, Опік, Показання, Протипоказання, Харчування, Шкіра, Омолодження, Довголіття/Longevity, Зморшки, Регенерація, Реабілітація, «Результат лікування» и т. п.) дали бы ссылки не по делу. С 2026-11-22 по просьбе клиники `0` ещё у частотных бытовых слов (Колаген, Гіалуронова кислота, Пептиди, Нутрієнти, БАДи, Філери, Детоксикація, Мікробіота, Кортизол, Менопауза, Рубець, Рідкий азот, М’язова маса) и общих фраз (Здорове старіння, Здорове довголіття, Хронічний стрес, Циркадні ритми, Гормональний баланс, Відновлення якості життя, Профілактика старіння, Індивідуальний план лікування, Комплексний чекап, Інформована згода); список `FREQUENT` в `src/build.py`, всего без автоссылок 46 терминов. Ещё `0` у направлений и услуг клиники (Пластична хірургія, Естетична медицина, Неофіброліфтинг®, Банк клітин): в статьях первое упоминание лучше вести на страницу услуги, это полезнее для SEO; пометка в `notes`. Решение редакции, можно поменять |
| `forms_uk` / `forms_ru` / `forms_en` | формы слова для поиска в тексте: падежи и число, синонимы из скобок (например «оксидативний стрес», «стовбурова ніша») |
| `notes` | что проверить глазами: слово не из словаря (формы построены по похожему), формы заданы вручную, совпадения с другими терминами |

## Правила автоссылок (фильтр `the_content`)

1. Ссылка только на **первое** упоминание термина в статье; всего не больше 5–7 ссылок на статью.
2. Не трогать заголовки (H1–H6), существующие ссылки, цитаты и саму страницу абетки.
3. **Сначала длинные формы**: «клітинна регенерація» раньше, чем «регенерація», иначе короткий термин перехватит длинный.
4. Совпадение по целым словам, без учёта регистра. Аббревиатуры (PRP, HIFU, RF-терапія, БАДи) — с учётом регистра.
5. Апострофы в тексте бывают трёх видов (`'` `’` `ʼ`) — перед сравнением приводить к одному. В CSV стоит `’`.
6. Формы брать по языку текущей версии (qTranslate): UA → `forms_uk`, RU → `forms_ru`, EN → `forms_en`.

## Как получены формы

Морфологические словари pymorphy3 (украинский и русский): падежи и число, прилагательные согласованы
с главным словом. Слова вне словаря склонены по похожим и отмечены в `notes`; для нескольких
(вік, чекап, секретом, сенолітики, екзосоми и др.) формы заданы вручную. Английский — единственное и множественное число.

Пересобрать после правок таблицы: `python3 docs/glossary/src/build.py docs/glossary/src` (нужны pymorphy3 и словари uk/ru;
термины — `src/terms.json`, переводы названий — `src/tr.txt`, результат — `src/out/`).
