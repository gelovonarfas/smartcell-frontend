# CHANGELOG — передачи Николаю

Каждая передача = тег `handoff-N`. Для каждого пункта помечено, как накатывать:
**файлы** — взять новую версию файла как есть; **разметка** — перенести правку
в соответствующий шаблон темы (файл секции ↔ template-part один к одному).

- **разметка** · статьи-образцы: с абзацев и заголовков тела сняты классы — образец теперь
  выглядит как вывод редактора. `gsap-animations.js` целится в `.vm-article__main > h2`.
- **файлы** · `vm-article.css`: правила прозы продублированы по тегу внутри
  `.vm-article__main` (`:not([class])`) — вывод редактора WordPress без классов выглядит
  как кит. Тело статьи = одно поле wysiwyg, репитер только для модулей; таблица в HANDOFF.
- **разметка + файлы** · статья: подсказка скролла (квадрат с точкой) убрана на всех экранах.
- **разметка + файлы** · картинки ниже первого экрана — `data-src`/`data-srcset`, подставляет
  `assets/js/img-lazy.js` за 300 px до вьюпорта; постер полосы подписки — `data-poster`.
  Родной `loading="lazy"` на медленной сети стартовал всю ленту вместе с обложкой первого
  слайда, и та ехала 11,6 с. `vm-featured.css`: слайд прижат к верху строки.
- **разметка + файлы** · слайдер журнала: скрытые кадры `loading="lazy"`, `vm-featured.js` греет
  следующий кадр и переключается только с готовым; отсчёт стартует после `load`.
- **разметка** · `<main id="content">` на страницах журнала; подписи кнопок «поділитись»
  начинаются с видимого текста; `preload` обложки статьи в `<head>`.
- **файлы** · `vm-featured.css`: все слайды в одной строке сетки, скрытые — `visibility: hidden`;
  высота блока постоянная, контент ниже не прыгает при смене материала (десктоп и телефон).
- **файлы + разметка** · `vm-rubrics`: аватар в фильтре — свой `tsepkolenko-avatar.png` 144² (29 KB)
  вместо портрета 328 KB.
- **стенд** · `scripts/bundle-css.py`: CSS минифицируется; стили первого экрана уходят
  инлайном в `<head>`, остальное грузится неблокирующе. Отрисовка не ждёт ни одного
  CSS-запроса. Николаю на проде — тот же приём: критический CSS инлайном, бандл через
  `preload` + `onload`.
- **разметка** · картинка модалки записи — `loading="lazy"`: в скрытом окне не грузится (−293 KB).
- **файлы** · `scenarios.js`: соседние кадры сценариев не тянутся на старте — десктоп в простое
  после load, телефон при первом касании переключателя (−950 KB на мобильном).
- **разметка + файлы** · постер хиро — `<picture class="sc-hero__poster">` под видео,
  а не атрибут `poster`: кадр под экран выбирает браузер без скрипта и рисует сразу
  после стилей (задержка отрисовки LCP 1 980 → 89 мс). `b01-hero.css`: слои постер →
  видео → скримы.
- **разметка + файлы** · хиро на телефоне: вертикальный `video/hero-mob.mp4` (720×1280,
  1,6 MB) и свой постер `img/hero-poster-mob.jpg`; выбор источника по `data-media`
  делает `video-lazy.js`. У всех `<video>` заданы `width`/`height`.
- **файлы** · `b00-announcement.css`: у `--announce-h` есть значение по умолчанию из
  вёрстки, замер скриптом его не меняет — хиро не прыгает при загрузке.
- **стенд** · сборка вырезает `@import` шрифта из бандла и грузит CSS шрифта неблокирующе;
  Николаю на проде — подключить шрифт `<link>`-ом с тем же приёмом, см. `docs/HANDOFF.md`.
- **стенд** · `scripts/bundle-css.py`: при сборке `dist` стили каждой страницы склеиваются
  в один файл (31 → 1 запрос на лендинге). Исходники по блокам не меняются; на проде
  Николай собирает свой бандл тем же порядком подключения.
