# Новая страница в ките SmartCell

Общие правила и рецепты — в навыке `web-kit` и его `references/`. Здесь только то,
что верно для этого проекта.

## Источник правды и документы

- `CLAUDE.md` — железные правила; `smartcell/DESIGN.md` — дизайн-система;
  `docs/HANDOFF.md` — карта блоков и полей для Николая; `CHANGELOG.md` — передачи.
- Макет: Figma `t3K32ifBrrW1kD2BBbp1tA`, по одному фрейму за запрос. Кадры —
  `download_assets` jpg, scale 1 и 2.
- Похожий готовый блок в `sections/` — образец для нового: там уже решены поля,
  отступы, состояния и мобильная раскладка. Статья-образец — `vm-article-oblik.html`.

## Имена и переменные

- Префикс лендинга `sc-`, журнала `vm-`; роли типографики `.sc-t-h2`, `.sc-t-body`,
  `.sc-t-lead`, `.sc-t-small`, `.sc-t-mini`, `.sc-t-caption`.
- `assets/css/tokens.css` — из Figma, не править. Чего нет в токенах — `assets/css/base.css`
  под `--sc-*`: шкала `--sc-space-0_5…`, `--sc-line` (0.7), `--sc-measure`, `--sc-dur*`,
  `--sc-ease*`, альфы `--sc-white-alpha-*`/`--sc-black-alpha-*`, `--sc-chip-pad`,
  `--sc-focus-w`/`--sc-focus-offset`, `--sc-field-ring-w`, `--sc-progress-h`,
  `--sc-neutral-600` (мелкий текст на светлых/синих полосах), `--sc-blue-200…800`,
  `--sc-action`, `--sc-ink-deep`, `--sc-glass-*`.
- Полоса контента: `--sc-pad-x` (= `--sc-band` + `--page-margin-x`); внутри плит на
  тёмном фоне вторых 80 не добавлять — край плиты не виден.
- Тёмные секции — `data-theme="inverse"`; переменные, которые «переворачиваются»,
  повторять внутри `[data-theme="inverse"]` (`var()` в `:root` резолвится в `:root`).
- Синие полосы (B08, подписка): кадр над белой подложкой + `::after` с
  `color-mix(blue-300 78%, blue-400)` в `mix-blend-mode: color`; ручки — тон и
  прозрачность видео в переменных блока.

## Готовые скрипты (переносятся как есть)

`header.js` (высоты `--header-h`/`--announce-h`, меню), `video-lazy.js` (`data-src`,
`data-media`, `data-poster`), `img-lazy.js` (`data-src`/`data-srcset`), `vm-featured.js`
(слайдер: греет следующий кадр, старт после `load`), `story.js`, `scenarios.js`
(предзагрузка в простое/по касанию), `reviews.js`, `gsap-animations.js` (вход шапки статьи:
`.vm-article__main > h2` и др.).

## Сборка стенда и передача

- `bash scripts/deploy.sh` → `dist` → Cloudflare `smartcell-frontend`. Новую страницу
  добавить в `CRITICAL` в `scripts/bundle-css.py` (tokens, base, шапка, первый экран).
- В `<head>` каждой страницы: preconnect к шрифтам и `preload as=style` до `tokens.css`;
  для LCP-картинки — `preload as=image`.
- Пуш в `main` → CI (сборка, битые ссылки, деплой при секретах); тег `handoff-N` → релиз
  с архивом. CHANGELOG: пункты с пометками **файлы** / **разметка** / **стенд**.
- Комментарии в коде — почему и дата; Николай читает их как документацию.

## Чек-лист перед сдачей блока

- [ ] шапка секции с `figma:` и `ACF:`; копия в странице с маркером `<!-- Секция — копия sections/x.html -->`
- [ ] обычный текст без классов, стили по тегу внутри контейнера; классы только у модулей
- [ ] ни одного литерала цвета/отступа/шрифта; локальные размеры — переменные с комментарием
- [ ] мобильный: один брейкпоинт, липкое скрыто, кнопки во всю ширину, порядок строк замерен
- [ ] состояния, `reduced-motion`, контраст мелкого текста ≥ 4.5
- [ ] медиа по `web-kit/references/media.md`: слот ×2, `width/height`, `data-src` вне первого экрана, видео через `data-src`
- [ ] страница в `CRITICAL`; нет подключений чужих блоков
- [ ] рендер на 1440 и 390, зонд геометрии, вычисленные стили `dist` = исходник
- [ ] Lighthouse mobile ≥ 90; выложено; коммит; строка в CHANGELOG
